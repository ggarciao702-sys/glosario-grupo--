## Terminos de Software
*(completada por el Estudiante 3)*
Tipos de Software:
SaaS (Software as a Service): Aplicaciones en la nube accesibles por internet, usualmente bajo suscripción.
Software Libre: Software que permite al usuario ejecutar, copiar, investigar, modificar y mejorar el código.
Software Privativo/Propietario: Software con restricciones en el uso, modificación o redistribución de su código fuente.
Código Abierto (Open Source): Software cuyo código fuente está disponible gratuitamente para modificaciones.
Frontend: Parte del software con la que interactúa el usuario.
Backend: Parte del servidor que procesa la lógica y datos.
API (Interfaz de Programación de Aplicaciones): Herramienta que conecta diferentes software.
Framework: Conjunto de plantillas y bibliotecas para facilitar el desarrollo.
QA (Quality Assurance): Proceso de pruebas para asegurar la calidad y funcionamiento.
Deploy (Despliegue): Poner el código en el servidor funcional.
Firmware: Software integrado que controla el hardware de un dispositivo específico.
Freeware: Software gratuito, pero no necesariamente libre.
Shareware: Software de evaluación con funcionalidades o tiempo limitado.
