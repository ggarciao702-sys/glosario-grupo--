# glosario-grupo--
"GPU"- Unidad de Procesamiento Grafico se encarga de procesar gráficos e imágenes. Es fundamental para videojuegos, diseño y edición de video.
"Placa Madre"- Motherboard Es la tarjeta principal del computador donde se conectan todos los componentes como el CPU,RAM y almacenamiento.
"Fuente de poder"- Power supply Suministra energía eléctrica a todos los componentes del computador para que funcionen correctamente
