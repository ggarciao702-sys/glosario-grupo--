## Terminos Generales de Programacion
Los términos generales de programación son:

Algoritmo: Conjunto ordenado de instrucciones para resolver un problema.
Código Fuente: El conjunto de líneas de texto escritas por el programador en un lenguaje de alto nivel.
Sintaxis: El conjunto de reglas que definen la estructura de un lenguaje de programación (como la gramática).
Bug/Error: Fallo en el código que causa un comportamiento inesperado.
Compilador/Intérprete: Programa que traduce el código fuente a lenguaje máquina (0s y 1s). 



Estructuras de Datos y Almacenamiento

Variable: Espacio de memoria con nombre utilizado para almacenar datos que pueden cambiar.
Tipo de dato: Clasificación de datos: enteros (1, 2), flotantes (3.14), booleanos (verdadero/falso), o cadenas de texto.
Array/Vector: Estructura que almacena una colección de elementos, usualmente del mismo tipo, de manera ordenada.

Estructuras de Control y Funciones

Condicionales (If/Else): Instrucciones que permiten al programa tomar decisiones basadas en condiciones.
Bucles/Ciclos (For/While): Instrucciones para repetir un bloque de código varias veces.
Función/Método: Un bloque de código reutilizable que realiza una tarea específica.

Conceptos Generales de Desarrollo

Framework: Conjunto de herramientas y bibliotecas predefinidas que facilitan el desarrollo de aplicaciones.
Front-end: Parte de la aplicación con la que el usuario interactúa (interfaz).
Back-end: Parte del software que gestiona la lógica, servidores y bases de datos. 

Entender estos conceptos es el primer paso para dominar cualquier lenguaje de programación, ya que la mayoría de los lenguajes modernos comparten estas mismas bases lógicas.
